CUSTOMER HANDOVER DOCUMENT

## 1. System Overview

### The Ferguson Bequest System is a web-based platform for managing:

- Attraction bookings
- Ticket allocation
- Waitlists
- Ticket draws
- Automated communication with users

### It provides:
- A user-facing booking system
- An admin interface for management

` ` `

## 2. Key Features

### Booking System:
- Browse attractions
- Book available slots
- Cancel bookings within allowed timeframe

### Waitlist System:
- Join waitlists when full
- May receive place if space becomes available

### Ticket Delivery:
- Tickets generated automatically
- Sent via email

### Ticket Draws:
- Used when demand exceeds capacity
- System selects participants

#### Email Notifications:
- Booking confirmations
- Tickets
- Reminders
- Feedback emails

` ` `

## 3. Admin Capabilities

### Administrators can:
- Manage attractions
- View bookings
- Run ticket draws
- Manage users and system data

### Access via:
/admin

` ` `

## 4. How the System Works

1. Users browse attractions
2. Users make bookings or join waitlists
3. System manages availability
4. Tickets are issued automatically
5. Emails keep users informed

` ` `

## 5. Requirements

- Hosting server
- Python or Docker support
- Email (SMTP) service

` ` `

## 6. Deployment Summary

### The system runs as:
- A web application
- Connected to a database
- Integrated with an email service

` ` `

## 7. Known Limitations

- Automated processes require setup (scheduler)
- Uses a lightweight database (SQLite)
- Not designed for very high traffic

` ` `
