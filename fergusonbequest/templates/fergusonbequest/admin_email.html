About this email type: {% if selected_type == "attraction_confirmation" %}

Sent immediately after a user successfully books an attraction.

{% elif selected_type == "draw_confirmation" %}

Sent immediately after a user enters a ticket draw.

{% elif selected_type == "attraction_cancellation" %}

Sent when a user cancels their attraction booking.

{% elif selected_type == "draw_cancellation" %}

Sent when a user cancels their draw entry.

{% elif selected_type == "attraction_distribution" %}

Sent when tickets are assigned to an attraction booking, either manually by staff or automatically 3 days before the event.

{% elif selected_type == "draw_distribution" %}

Sent when tickets are assigned to a draw winner after they've accepted their win.

{% elif selected_type == "draw_winner" %}

Sent to the winner of a draw immediately after the draw is run. Includes links to accept or reject the tickets, with a 72-hour deadline to respond.

{% elif selected_type == "attraction_reallocation" %}

Sent when a cancelled attraction slot is reassigned to the next person on the waiting list.

{% elif selected_type == "draw_reallocation" %}

Sent to a new winner if the original winner declines or fails to respond within 72 hours. Includes links to accept or reject with another 72-hour deadline.

{% elif selected_type == "attraction_reminder" %}

Sent 1 day before an attraction visit. Reminds the user of their upcoming booking and provides relevant details.

{% elif selected_type == "draw_reminder" %}

Sent 1 day before a draw event (if the user has tickets). Reminds them of their upcoming visit and provides ticket information.

{% elif selected_type == "announcement" %}

General announcements sent to all users.

{% elif selected_type == "custom" %}

Custom emails for specific communications. You can select individual users or groups to receive this email.

Select an email type to see its description.
